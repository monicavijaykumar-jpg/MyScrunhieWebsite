🪄 Scrunchie Magic (MyScrunchieWebsite)

Welcome to Scrunchie Magic - A modern, responsive e-commerce web application designed for custom handmade scrunchies!

🌐 Live Website: https://scrunchiemagic.netlify.app

✨ Features:

Product Showcase: Attractive display of handmade satin and butterfly bow scrunchies.

Interactive UI: Smooth navigation, dropdown product variants, and responsive layout styled using modern CSS.

Client-Side Functionality: Built with vanilla JavaScript for interactive elements.

🛠️ Technologies Used:

HTML5 (Semantic layout and structure)

CSS3 (Styling, responsiveness, and clean UI design)

JavaScript (Interactive features and user experience)

Figma (UI/UX prototyping and layout design)
